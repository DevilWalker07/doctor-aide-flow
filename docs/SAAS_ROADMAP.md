# DOUTOR AJUDA - Roadmap SaaS

Este branch adiciona a primeira camada do motor clinico para transformar o prototipo em SaaS.

## Entregue neste branch

- Tipos clinicos padronizados.
- Conversor de paciente local para paciente clinico.
- Calculo de dia de antibiotico com regra D0/D1.
- Detector de riscos clinicos.
- Gerador de linhas de passagem de plantao.
- Gerador HTML para mapa imprimivel.
- Entrada de mapa no dashboard.

## Proximas etapas

1. Substituir localStorage por Supabase como fonte principal.
2. Criar entidade de plantao.
3. Implementar login e protecao de rotas.
4. Criar upload real de documentos.
5. Integrar agentes Agno no backend.
6. Integrar Docling para converter PDF, DOCX e imagens em texto/markdown.
7. Deploy no Vercel.
